# Куратор: школьная программа

Личный оффлайн-куратор — сначала для одного человека, без аккаунтов и без
сервера. Главная страница (`index.html`) каждый день показывает, что делать
сегодня, на основе твоего прогресса: сколько терминов геометрии отмечено
выученными и что показала последняя диагностика по профильной математике.

Открыть: https://typeidpd-hue.github.io/fuzzy-doodle/ (после включения
GitHub Pages для репозитория, ветка `main`, папка `/`).

## Структура

| Файл               | Назначение |
|--------------------|------------|
| `index.html`       | Главная страница-куратор: план на сегодня, общий прогресс, ссылки на разделы |
| `terms.html`       | Геометрия 7–11: термины и формулы (планиметрия 7–9, стереометрия 10–11), с поиском и отметками «выучено» |
| `diagnostic.html`  | Диагностика по профильной математике: пробелы по темам и план до целевого балла ЕГЭ |
| `manifest.json`    | Описание PWA (нужен браузеру отдельным файлом по спецификации) |
| `sw.js`            | Service worker для офлайн-кэша (тоже требуется отдельным файлом) |
| `icon.svg`         | Иконка приложения |

`manifest.json` и `sw.js` — инфраструктурные файлы без учебного контента,
без которых веб-платформа не даёт странице устанавливаться и работать
офлайн. Весь контент (геометрия, задачи диагностики, логика плана) — в
`index.html`, `terms.html` и `diagnostic.html`.

## Что оптимизировано

- **Скорость загрузки.** Никаких внешних запросов к CDN — только системные
  шрифты устройства, рендер мгновенный и с первого байта. Списки тем
  обёрнуты в `content-visibility: auto`.
- **Офлайн-работа.** `sw.js` кэширует все три страницы после первого
  открытия — куратор работает без сети (баннер сверху сообщает, когда вы
  офлайн). Весь прогресс — в `localStorage`.
- **Мобильная вёрстка и удобство.** Поля ввода 16px (без авто-зума iOS),
  кнопки и чекбоксы от 44px (стандарт для тапа), отступы под вырез экрана,
  убран синий хайлайт при тапе.
- **PWA.** Можно «Добавить на экран Домой» — полноэкранный режим, своя
  иконка, работает офлайн.

## Личный куратор: как это работает

Главная страница ничего не считает сама — она читает то, что уже сохранили
`terms.html` и `diagnostic.html` в `localStorage`, и складывает из этого короткий
план на сегодня:

- если диагностик ещё не было — предлагает пройти первую;
- если были — берёт самые слабые темы из последней попытки и предлагает
  количество повторений (та же логика, что и в самой диагностике);
- если последняя диагностика была 5+ дней назад — напоминает пройти заново;
- если геометрия вообще не открывалась — напоминает начать с неё.

Это простая логика без нейросетей и без скрытых вычислений — весь код
можно прочитать прямо в `<script>` каждой страницы.

## Важное честное ограничение

Задачи в `diagnostic.html` составлены по образцу структуры профильного ЕГЭ,
а не взяты из реальных вариантов ФИПИ. Оценка в баллах — грубый ориентир по
проценту решённого, а не официальная таблица перевода первичного балла (она
пересчитывается Рособрнадзором каждый год). Для точного перевода — смотри
фипи.ru или ege.rustest.ru.

## Roadmap

Следующий шаг — добавление других школьных предметов (на главной уже
зарезервированы карточки «скоро» для физики и русского языка) и, когда
появится доступ к поиску в интернете, замена банка тренировочных задач на
актуальный. Более крупная идея — куратор, который анализирует фото домашних
заданий через нейросеть с распознаванием изображений — требует отдельного
бэкенда и платных запросов к модели и в эту статическую версию не входит:
подробности и оценка сроков обсуждались в переписке, при необходимости
попроси собеседника-Claude напомнить план.
