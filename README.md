# Геометрия 7–11: термины и формулы

Оффлайн-справочник по геометрии: планиметрия (7–9 класс) и стереометрия —
объёмы и площади поверхностей (10–11 класс). Все термины, формулы и логика
приложения собраны в одном файле — `index.html`. Ничего внешнего для работы
контента не требуется.

Открыть после включения GitHub Pages для репозитория (ветка, на которую это
зальётся, папка `/`).

## Что оптимизировано

- **Скорость загрузки.** Убраны внешние запросы к Google Fonts — раньше
  страница ждала загрузку шрифтов с сети перед отрисовкой текста. Теперь
  используются системные шрифты устройства, рендер мгновенный и с первого
  байта. Списки тем обёрнуты в `content-visibility: auto`, чтобы браузер не
  тратил время на вёрстку и покраску блоков, которые ещё не видны на экране.
- **Офлайн-работа.** Добавлен `sw.js` (service worker) и `manifest.json` —
  минимальная PWA-обвязка. После первого открытия страница и её содержимое
  кэшируются, и приложение открывается и работает без сети (баннер сверху
  сообщает, когда вы офлайн). Прогресс изучения хранится в `localStorage` —
  тоже без сети.
- **Мобильная вёрстка и удобство.** Поле поиска увеличено до 16px (чтобы
  iOS не масштабировал страницу при фокусе), кнопки и чекбоксы увеличены до
  44px по высоте (стандарт для комфортного тапа), добавлены отступы под
  вырез/чёлку экрана (`env(safe-area-inset-*)`), убран синий хайлайт при
  тапе на iOS/Android.
- **PWA.** Страницу можно «Добавить на экран Домой» — она получит иконку
  (`icon.svg`), будет открываться в полноэкранном режиме без адресной
  строки браузера и продолжит работать офлайн.

## Файлы репозитория

| Файл            | Назначение |
|-----------------|------------|
| `index.html`    | Всё содержимое и вся логика приложения — единственный файл с геометрией |
| `manifest.json` | Описание PWA (нужен браузеру отдельным файлом по спецификации) |
| `sw.js`         | Service worker для офлайн-кэша (тоже требуется отдельным файлом) |
| `icon.svg`      | Иконка приложения |

`manifest.json` и `sw.js` не содержат учебного контента — это
инфраструктурные файлы, без которых веб-платформа не даёт странице
устанавливаться и работать офлайн. Вся геометрия (термины, формулы,
диаграммы, логика поиска и прогресса) находится только в `index.html`.

## Roadmap

В обсуждении была озвучена более крупная идея — приложение, которое
покрывает не только геометрию, а все школьные предметы, объясняет материал,
готовит к экзаменам и подстраивается под уровень ученика. Это отдельный,
намного больший проект. Текущий репозиторий — конкретный первый шаг
(геометрия, офлайн, для мобильных) с архитектурой (один файл со структурой
данных по главам), которую можно будет использовать как шаблон при
расширении на другие предметы.
